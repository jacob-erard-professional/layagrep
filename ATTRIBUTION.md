# Attribution

## Laya model

LayaGrep uses [`convaiinnovations/laya`](https://huggingface.co/convaiinnovations/laya),
an open-source System 1 decision model released by
[Convai Innovations](https://huggingface.co/convaiinnovations) under the Apache 2.0
license. Model weights are downloaded directly from Hugging Face during
`layagrep setup`; they are not stored in this Git repository.

LayaGrep is an independent integration and is not presented as an official Convai
Innovations product.

## Original project

LayaGrep is derived from and continues
[JevGrep](https://github.com/nassim-arifette/jevgrep), originally created by
Nassim Arifette and released under the MIT license. The original repository supplied
the repository-scanning architecture, safety and response contracts, CLI and MCP
foundations, fixtures, and test infrastructure.

The original copyright and MIT license notice remain in [`LICENSE`](LICENSE), and the
Git history retains the original commits and authorship.
